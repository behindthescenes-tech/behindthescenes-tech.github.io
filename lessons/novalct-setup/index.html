NovaLCT: أول setup لشاشة LED

الدرس بيشرح توصيل نظام NovaStar والخطوات الأساسية في NovaLCT. الرسومات توضيحية، مش لقطات شاشة من البرنامج. أسماء القوائم والأزرار بالإنجليزي زي ما بتظهر في البرنامج، والخطوات بتختلف حسب الإصدار وموديل الـ controller وكارت الاستقبال.

1. التوصيل: مسار الفيديو ومسار التحكم

الفيديو بيطلع من الكمبيوتر أو الـ media server للـ sending card (controller) بكابل حسب الموديل، زي HDMI أو DVI أو SDI. من الـ controller بيروح للكابينات بكابل Ethernet لكن ده بيشيل بيانات LED مش شبكة عادية، فماتوصلوش بسويتش أو راوتر. NovaLCT مسار تاني: بيتوصل للـ controller بـ USB أو شبكة حسب الموديل، وبيبعت الإعدادات بس.

2. خطوات الضبط

  1. قبل ما تغيّر أي حاجة: لو الشاشة شغالة، خد نسخة من الإعدادات الحالية. من Screen Configuration تقدر تعمل Save to File، وبعد Save المرة الجاية البرنامج بيسألك لو عايز تحفظ ملف backup على الكمبيوتر.
  2. ادخل من User > Advanced Synchronous System User Login. كلمة المرور الافتراضية في دليل NovaStar هي admin، لكن ممكن تكون اتغيرت على جهازك.
  3. افتح Screen Configuration واختار المنفذ (communication port) اللي الكمبيوتر متوصل بيه، ثم Next.
  4. تبويب Receiving Card: ده بيحدد مقاس الكابينة. من Import أو Load from Cloud (VNNOX Care) حمّل ملف الكابينة (.rcfgx أو .rcfg) اللي يطابق موديلها، أو اضبطها يدويًا. بعد كده اضغط Send واختار All Receiving Card أو كروت محددة. لو نسخة الفيرموير مش مطابقة للملف البرنامج بيسألك عن الترقية. تقدر تعمل Export لملف .rcfgx كنسخة احتياطية.
  5. تبويب Screen Connection: حدد عدد الشاشات (1 لو كذا منفذ بيحملوا أجزاء من نفس الشاشة) واضغط Configure، واكتب عدد الأعمدة والصفوف لكروت الاستقبال واختار output port.
  6. وصّل الكابينات في البرنامج بنفس مسار الكابل الحقيقي (Custom connection بالضغط أو السحب)، واضبط مقاس الحمل (width/height) لكل كارت.
  7. اضغط Send to HW وشوف الصورة. مفيش كابينة فاضية قبل الحفظ، والكابينة اللي مش موجودة تتعمل blank.
  8. لما الصورة تطلع صح اضغط Save عشان الإعداد يتحفظ في الجهاز. الفرق: Send to HW بيبعت الإعداد للجهاز، Save بيحفظه جوه الجهاز، وSave to File بيحفظ ملف على الكمبيوتر بس (للنسخ الاحتياطي). كلهم مهمين.

3. ترتيب الكابل

الأرقام في الرسم مثال. اللي بيحدد الترتيب هو مسار الكابل الفعلي من الـ output port لحد آخر كابينة، سواء أفقي أو رأسي. ارسم مسار الكابل أو صوّره وقت التركيب.

لو الصورة طالعة غلط: راجع مقاس الكابينة (البكسل) وترتيب التوصيل في Screen Connection. استخدم Test Pattern من البرنامج (أحمر، أخضر، أزرق، أبيض) تتأكد إن كل كابينة بتعرض مكانها. تقدر كمان تعمل Detect Communication Status يشوف الاتصال بين كروت الاستقبال والمنفذ.
